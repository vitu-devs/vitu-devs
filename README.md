## 📌 Projeto em Destaque

### 🏗️ Pipeline ETL Analítico — Grupo NovaTech Holding
**Engenharia de Dados end-to-end com arquitetura Medalhão e orquestração** · [`github.com/vitu-devs/novatech`](https://github.com/vitu-devs/novatech)

- Pipeline ETL end-to-end consolidando dados de **4 empresas** de uma holding (e-commerce, ERP, logística e pagamentos) em um único ambiente analítico consultável.
- Arquitetura em camadas **Medalhão (Bronze / Silver / Gold)**: de um OLTP em **3FN no PostgreSQL** até um **Star Schema** pronto para consumo (fluxo OLTP → OLAP).
- Camada **Silver em PySpark** (limpeza, cast, joins, agregações) e **Gold em Pandas** (modelagem dimensional, grão por item de pedido).
- Orquestração via **Apache Airflow (DAG)** e ambiente containerizado com **Docker/Compose** + manifestos **Kubernetes** (demo).
- Documentação de arquitetura e decisões técnicas, com **dashboard executivo em Power BI** conectado ao Data Warehouse.

`Python` · `PySpark` · `Pandas` · `SQLAlchemy` · `PostgreSQL` · `Airflow` · `Docker` · `Kubernetes` · `Power BI`
